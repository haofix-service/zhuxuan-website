筑軒國際設計 官網雛形

使用方式
1. 解壓縮後，用瀏覽器開啟 index.html 即可預覽。
2. index.html 與 images 資料夾必須放在同一層，不可分開，否則圖片不會顯示。
3. 字體（Noto Sans TC、Cormorant Garamond）由 Google Fonts 載入，離線時會改用系統字體。

內容說明
- 虛線框標示「待補」的欄位，是等待補充的資料（電話、LINE、地址、坪數、年份、設計說明、收費流程等）。
- 預約表單目前沒有連線，送出的內容不會傳給任何人。
- 右上角可切換淺色與深色。
- 照片取自筑軒作品集。正式上線前，請確認建商與代銷公司的名稱及照片公開使用授權。
